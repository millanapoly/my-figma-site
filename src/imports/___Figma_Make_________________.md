# ТЗ для Figma Make: дашборд «Аналитика продаж»

## 1. Что нужно получить

Создать в Figma Make интерактивный desktop-прототип дашборда «Аналитика продаж» для личного кабинета дистрибьютора. Визуально взять за основу приложенный референс дашборда, но **не переносить синий выделенный / закрашенный блок с KPI под фильтрами**. После строки фильтров сразу должны начинаться карточки графиков.

Графики не нужно строить как полноценные Figma-компоненты. Для экономии токенов и упрощения генерации использовать приложенные PNG-картинки графиков как статичные изображения:

- `chart_plan_fact_sell_in.png` — верхняя левая карточка.
- `chart_plan_fact_sell_out.png` — верхняя правая карточка.
- `chart_sell_in_sell_out_comparison.png` — нижняя широкая карточка.
- `reference_dashboard_without_blue_block.png` — общий визуальный референс без синего блока, использовать только как ориентир по композиции.

## 2. Основной промпт для Figma Make

```text
Создай интерактивный desktop-прототип страницы личного кабинета «Аналитика продаж».

Формат: один основной frame 1440 × 768 px, светлый dashboard UI, русский язык интерфейса. Стиль аккуратный корпоративный: светло-серый фон страницы, белые карточки, тонкие серые границы, тёмно-синий акцент для активных кнопок и заголовков. Не создавай KPI-плашки/summary cards под фильтрами. Игнорируй синий выделенный блок на исходном скриншоте: его в новом макете быть не должно.

Структура экрана:
1. Заголовок страницы: «Аналитика продаж».
2. Верхняя панель фильтров в одну строку:
   - подпись «Период» и поле выбора периода от–до;
   - быстрые кнопки периодов: «Предыдущий год», «Текущий год», «Предыдущий квартал», «Текущий квартал», «Последние 5 кварталов»;
   - селектор «Детализация» со значениями «Месяц», «Квартал»;
   - селектор «Линейка» со значениями «Все линейки» и конкретными товарными линейками;
   - иконка информации справа.
3. Ниже фильтров размести 3 карточки графиков:
   - верхняя строка: 2 карточки по 50% ширины с зазором 20 px;
   - нижняя строка: 1 широкая карточка на всю ширину контента;
   - карточки должны начинаться сразу после фильтров, без промежуточного блока показателей.

Используй статичные PNG-изображения графиков, не перерисовывай графики вручную:
- В верхнюю левую карточку вставь image asset `chart_plan_fact_sell_in.png`.
- В верхнюю правую карточку вставь image asset `chart_plan_fact_sell_out.png`.
- В нижнюю широкую карточку вставь image asset `chart_sell_in_sell_out_comparison.png`.
Изображения должны занимать всю внутреннюю область карточек, сохранять пропорции, без обрезки текста, легенд и подписей.

Дефолтное состояние:
- выбран быстрый период «Последние 5 кварталов»;
- в поле периода показано «01.04.2025 – 30.06.2026»;
- детализация: «Квартал», потому что период больше 1 года;
- линейка: «Все линейки»;
- графики показывают общие план/факт и факты Sell-In/Sell-Out.

Состояния и кликабельность:
1. Поле «Период» кликабельное. По клику открывается overlay/выпадающая панель календаря:
   - два поля «Дата начала» и «Дата окончания»;
   - календарная сетка или упрощённый date-range picker;
   - кнопки «Применить» и «Сбросить»;
   - при нажатии «Применить» overlay закрывается, выбранный диапазон отображается в поле периода.
2. Быстрые кнопки периода кликабельные. По клику меняется активная кнопка и текст в поле периода:
   - «Предыдущий год» → «01.01.2025 – 31.12.2025»;
   - «Текущий год» → «01.01.2026 – 31.12.2026»;
   - «Предыдущий квартал» → «01.01.2026 – 31.03.2026»;
   - «Текущий квартал» → «01.04.2026 – 30.06.2026»;
   - «Последние 5 кварталов» → «01.04.2025 – 30.06.2026».
   Активная кнопка — тёмно-синяя заливка, белый текст. Остальные — белая заливка, серая граница, тёмный текст.
3. Селектор «Детализация» кликабельный. По клику открывается dropdown со значениями:
   - «Месяц»;
   - «Квартал».
   При выборе значение отображается в поле. Dropdown закрывается.
4. Селектор «Линейка» кликабельный. По клику открывается dropdown со значениями:
   - «Все линейки»;
   - «ЭСТЕЛАЙТ АСТЕРИА»;
   - «ЮНИВЕРСАЛ ФЛОУ»;
   - «БАЛК ФИЛЛ ФЛОУ»;
   - «ЭСТЕЛАЙТ ПОСТЕРИОР»;
   - «БОНД ФОРС»;
   - «БОНД УНИВЕРСАЛ II ТОКУЯМА».
   Выбранное значение отображается в селекторе. Для выбранной строки в dropdown показать галочку или подсветку.
5. Иконка информации кликабельная. По клику показать tooltip: «Данные обновляются после загрузки отчетности. При выборе линейки графики пересчитываются по выбранной категории». Tooltip закрывается по клику вне него.

Важно по графикам:
- В прототипе графики могут оставаться теми же PNG после смены фильтров. Не нужно имитировать пересчёт данных.
- Не создавать отдельные графики для каждой линейки.
- Не добавлять график остатков и не показывать остатки.
- Визуально сохранить русские названия графиков и легенды на изображениях.

Визуальные параметры:
- Ширина контентной области: 1400 px, отступы по 20 px от краёв frame.
- Фон страницы: #F6F8FA.
- Карточки: #FFFFFF, border #E3E8EF, radius 8–12 px, лёгкая тень или без тени.
- Основной текст: #1F2A44.
- Акцентный синий: #0B3D67.
- Вторичный текст: #6B7280.
- Высота строки фильтров: примерно 34–40 px.
- Расстояние между строкой фильтров и графиками: 24–28 px.
- Расстояние между карточками: 20 px.

Компоненты, которые нужно сделать:
- Button / quick period с вариантами default, hover, active.
- Date range selector с default/open state.
- Dropdown selector с default/open/selected states.
- Chart card image container.
- Tooltip для иконки информации.

Критерии приемки макета:
- На экране ровно 3 графика: «План/Факт Sell-In», «План/Факт Sell-Out», «Сравнение Sell-In / Sell-Out (факт)».
- Под фильтрами нет KPI-блока и нет синего выделенного блока из референса.
- Все основные селекторы кликабельны и открывают соответствующие overlay/dropdown/tooltip.
- Быстрые кнопки периода имеют активное состояние.
- Интерфейс полностью на русском языке.
- Графики вставлены как PNG-изображения, а не построены из множества Figma-элементов.
- Макет визуально похож на приложенный dashboard reference: лёгкий, таблично-аналитический, с большим количеством воздуха и аккуратными карточками.
```

## 3. Логика данных для подписи в макете

В прототипе расчёты не выполняются, но подписи и состояния должны соответствовать продуктовой логике:

| Элемент | Логика |
|---|---|
| Период по умолчанию | Текущий квартал + 4 предыдущих квартала |
| Быстрые периоды | Предыдущий год, текущий год, предыдущий квартал, текущий квартал, последние 5 кварталов |
| Детализация по умолчанию | Если период больше 1 года — «Квартал», если 1 год или меньше — «Месяц» |
| Селектор линейки | «Все линейки» или одна конкретная линейка, множественный выбор не нужен |
| График 1 | План/факт закупок Sell-In |
| График 2 | План/факт сбыта Sell-Out |
| График 3 | Сравнение фактических Sell-In и Sell-Out |
| Остатки | Не отображать |

## 4. Что не делать в Figma Make

- Не переносить синий выделенный блок из скриншота.
- Не создавать KPI-карточки «План Sell-In / Факт Sell-In / План Sell-Out / Факт Sell-Out» под фильтрами.
- Не строить сложные интерактивные графики из отдельных столбцов, линий и подписей.
- Не добавлять лишние разделы, таблицы, меню слева или верхнюю навигацию, если их нет в референсе.
- Не использовать английские подписи в интерфейсе, кроме терминов Sell-In / Sell-Out в названиях графиков.
